3. Slack HMAC-SHA256 Signature Verification & Events API

Slack requests require raw byte buffering before JSON parsing. Base string formula: v0:${timestamp}:${rawBody}. Evaluated using crypto.timingSafeEqual to prevent timing attacks, with a strict ±300s window. 

// HMAC Calculation & Verification Formula:
const sigBasestring = 'v0:' + req.headers['x-slack-request-timestamp'] + ':' + req.rawBody;
const expectedSig = 'v0=' + crypto.createHmac('sha256', SLACK_SIGNING_SECRET)
                                 .update(sigBasestring)
                                 .digest('hex');

const expectedBuf = Buffer.from(expectedSig, 'utf8');
const signatureBuf = Buffer.from(req.headers['x-slack-signature'], 'utf8');

if (expectedBuf.length !== signatureBuf.length || !crypto.timingSafeEqual(expectedBuf, signatureBuf)) {
  return res.status(401).send('Invalid signature');
}

4. Express Integration & Middleware Ordering Discipline

In bot/whatsapp-bot.js, Slack adapter MUST be mounted before global express.json() to capture raw request buffers. WhatsApp adapter is mounted at /webhook, setting req._gatewayHandled = true so downstream handleWebhookPost skips duplicate Redis marks and emoji reactions. 

// bot/whatsapp-bot.js Integration Snippet
const { createSlackRouter, createWhatsAppRouter } = require('./gateway');

const app = express();

// 1. Slack Gateway mounted BEFORE express.json() to capture raw bytes
app.use('/api/slack', createSlackRouter({ dispatch: handleWebhookPost }));

// 2. Global JSON & URL-encoded parsing for core app
app.use(express.json());

// 3. WhatsApp Gateway mounted at /webhook
app.use('/webhook', createWhatsAppRouter({
  dispatch: handleWebhookPost,
  handleBroadcastStatus: handleBroadcastStatusWebhook,
}));
